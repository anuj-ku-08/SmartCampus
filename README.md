# Smart Student Academic & Hostel Attendance System

A unified, full-stack campus management platform integrating **10-second dynamic rolling QR code attendance**, **GPS geofencing verification**, **hostel night curfew roll calls**, and **digital outpass workflows** for students, faculty, wardens, and administrators.

---

## Key Highlights

- **Dynamic Rolling QR (Anti-Proxy)**: 10-second rotating cryptographic session tokens generated by faculty prevent students from sharing static screenshots.
- **GPS Geofencing**: Verifies student device coordinates against lecture hall coordinates using the Haversine formula (configurable radius, e.g., 50 meters).
- **Night Curfew & Roll Call**: Digital room-by-room hostel attendance with automated guardian alerts for curfew absentees.
- **Digital Outpass Management**: Students submit day/home outpass requests; wardens review, approve, or reject them with audit remarks.
- **Role-Based Access Control (RBAC)**: Dedicated secure portals for **Students**, **Faculty**, **Hostel Wardens**, and **Campus Administrators**.
- **Admin Credential Management**: Administrators can provision individual passwords or execute batch credential resets across roles.
- **Camera & Location Access**: Built with modern web APIs (`getUserMedia` camera scanner and `navigator.geolocation`).

---

## Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide React, `html5-qrcode`
- **Backend**: Node.js, Express, TypeScript, `jsonwebtoken` (JWT), `bcryptjs`
- **Build & Bundler**: Vite (client SPA) + `esbuild` (server CommonJS bundling)
- **Deployment**: Production-ready for Google Cloud Run, Render.com, Railway, or Fly.io

## Quick Start (Local Development)

### 1. Prerequisites
- **Node.js** v18 or higher (v20+ recommended)
- **npm** v9 or higher

### 2. Installation
Clone this repository and install dependencies:
```bash
git clone https://github.com/your-username/smart-attendance-system.git
cd smart-attendance-system
npm install
```

### 3. Environment Variables (Optional)
Create a `.env` file in the root directory:
```env
PORT=3000
NODE_ENV=development
JWT_SECRET=your-secure-jwt-secret-key
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

> **Note**: Camera scanning and GPS geofencing require a secure context. Modern browsers treat `http://localhost` as secure, but mobile access requires **HTTPS**.

## Production Build

To compile both the React client frontend and the Express backend bundle:

```bash
npm run build
```

This generates:
- `dist/index.html` & client static assets (via Vite)
- `dist/server.cjs` (bundled standalone Node server via `esbuild`)

To test the production build locally:
```bash
npm start
```

## Deployment Guide

### Deploying to Render.com

1. Create a new **Web Service** on [Render.com](https://render.com) and link your GitHub repository.
2. Configure the following service settings:
   - **Environment**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Auto-Deploy**: `Yes`
3. Add any custom environment variables (e.g., `JWT_SECRET`).
4. Click **Create Web Service**. Render automatically assigns a free `https://*.onrender.com` domain with free SSL/TLS encryption.

> **Crucial for Render**: Ensure the Build Command includes `npm run build` so `dist/server.cjs` is compiled prior to `npm start`.

### Deploying to Google Cloud Run

This project is fully compatible with Google Cloud Run and containerized platforms.
```bash
# Build Docker image
docker build -t smart-attendance-system .

# Run container
docker run -p 3000:3000 smart-attendance-system
```

### Deploying to Railway / Fly.io

- **Build Command**: `npm run build`
- **Start Command**: `npm start`
- Railway and Fly.io automatically detect the `package.json` scripts and supply free HTTPS subdomains.

## HTTPS Requirement for Mobile Testing

Modern mobile browsers (Chrome on Android, Safari on iOS) **require HTTPS** to allow:
1. **Camera API** (`navigator.mediaDevices.getUserMedia`) for scanning QR codes.
2. **Geolocation API** (`navigator.geolocation.getCurrentPosition`) for proximity validation.

When deployed to Google Cloud Run, Render, or Railway, HTTPS is provided automatically.
